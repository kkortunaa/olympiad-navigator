# Показ сайта через Wi-Fi

Все зрители и Mac должны быть в одной сети Wi-Fi. Публичный домен не нужен.

## Запуск перед презентацией

```sh
cd /Users/kkortunaa/Documents/project_pepepep/scuns
.venv/bin/python presentation/start_wifi.py
```

Скрипт определяет текущий Wi-Fi IP, проверяет свободный порт 8001, создаёт
`site-qr.png` и `site-url.txt` в этой папке, проверяет считывание PNG и запускает
Django. Вставь **обновлённый** PNG в презентацию, сохрани белую рамку.
QR ведёт на главную страницу: зрители могут сразу пользоваться гостевым режимом.

Для подготовки QR без запуска: `.venv/bin/python presentation/start_wifi.py --prepare-only`.
Адрес можно задать явно: `--host 192.168.1.10`; порт: `--port 8002`.
Генератор использует встроенные CoreImage/Vision и Swift macOS, дополнительные
Python зависимости не устанавливаются.

## Во время показа

- Не закрывай процесс сервера, не выключай компьютер и не отправляй его в сон.
- На телефоне подключись к той же Wi-Fi сети и сначала открой адрес из `site-url.txt`.
- При смене сети или IP запусти скрипт заново и замени QR на слайде.
- Остановка сервера: Ctrl+C в терминале, где он запущен.
- Если Mac показывает запрос брандмауэра для Python, разрешение входящих соединений
  пользователь выдаёт сам. Скрипт не меняет брандмауэр.
- В школьной/гостевой сети может быть изоляция клиентов. Тогда одна Wi-Fi сеть
  не гарантирует доступ: понадобится сеть без изоляции или отдельное размещение.

Это временный показ через HTTP в доверенной сети. Используй гостевой режим или
тестовые аккаунты. DEBUG отключён; статика обслуживается Django через `--insecure`
только для этого запуска. Основные настройки проекта не меняются. Используется
текущая база: новые аккаунты и изменения зарегистрированных пользователей сохраняются.
Сервер слушает только выбранный Wi-Fi адрес. Это не рабочее размещение в интернете.

## Выступление на минуту

1. **0–10 с — идея.** «Это Олимпиадный навигатор: он помогает выбрать олимпиаду,
   не пропустить регистрацию и организовать подготовку в одном месте».
2. **10–25 с — олимпиады.** «В каталоге 60 олимпиад. Есть поиск, фильтр по предметам,
   сортировка по срокам регистрации и избранное. В карточке — даты туров, место
   и формат проведения, ссылки на источники и регистрацию».
3. **25–40 с — подготовка.** «Здесь собраны ссылки на задания прошлых лет.
   На главной можно запланировать задачи и отмечать выполнение.
   Календарь активности показывает, насколько регулярно я занимаюсь».
4. **40–50 с — сроки.** «Для выбранных олимпиад сервис показывает совпадения туров
   и напоминания о ближайших событиях. Уведомления работают, пока сайт открыт».
5. **50–60 с — аккаунт и приглашение.** «В аккаунте подготовка сохраняется между
   устройствами. Сайт работает на Django, данные хранятся в базе и обновляются
   парсером Selenium. Подключайтесь к нашей Wi-Fi сети и сканируйте QR — попробовать
   можно сразу без регистрации».
