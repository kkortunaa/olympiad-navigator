## Повторная проверка

```bash
python manage.py audit_catalog_links --report link-audit.json --workers 6 --timeout 12
```

Команда читает каталог и записывает только отчёт. Повторяющиеся URL проверяются один раз. Запросы выполняются с ограниченным числом потоков; ответы 403, 429, 5xx и ошибки TLS не считаются удалёнными страницами.

## Обновление PythonAnywhere

Из папки репозитория выполнить `git pull`, активировать окружение и из папки с `manage.py` выполнить `python manage.py migrate`. Затем нажать Reload на вкладке Web. Новые миграции исправляют ссылки без повторной загрузки каталога.

Проверка кода: 57 тестов парсера и ссылок пройдены. Новые адреса ЮМШ, ОРМО и НТО дополнительно проверены прямыми GET-запросами; ответы HTTP 200. Автоматическая проверка не является ручным просмотром содержимого всех 1 073 страниц.

## Общая обработка всех кнопок регистрации

Повторно проверены все 1 072 оставшиеся уникальные ссылки, включая 29 различных форм регистрации. Недоступность обнаружена также у форм «Будущего Сибири» (ошибка TLS), РГГУ (ошибка TLS), НТО (HTTP 200, но заголовок сообщает о временной недоступности) и «Культуры и искусства» (ссылка в административный раздел).

Добавлена таблица CatalogLinkCheck, хранящая результаты сетевых проверок. Неудачная проверка не удаляет исходный URL. При выводе каталога, расписания, профилей и API недоступная ссылка заменяется переходом на доступную страницу организатора, а если и она недоступна — на карточку источника. Подпись перехода различает прямую регистрацию и страницу с условиями участия. Внешние запросы при открытии страницы не выполняются. Коды 403 и 429 учитываются как возможное ограничение для роботов и не скрывают URL автоматически. Повторная успешная проверка возвращает прямой переход.

Для сохранения статусов: `python manage.py audit_catalog_links --report link-audit.json --save-checks`. Проверку следует повторять после обновления каталога. Разовые тайм-ауты перепроверяются с увеличенным ожиданием. Статусы отражают доступность из окружения проверки; они не доказывают удаление сайтов и не гарантируют доступность из любой сети.

Миграции 0008 и 0009 добавляют таблицу и начальные сведения о найденных проблемах, поэтому для исправления на существующем сайте достаточно обновить код и выполнить `python manage.py migrate`, затем Reload. Для актуализации доступности без изменения кода используется команда с `--save-checks`.

Проверка после общей обработки: 73 теста модуля олимпиад успешно пройдены. Дополнительно отрендерены каталог и все 60 страниц олимпиад на реальной локальной базе: ссылок, помеченных недоступными, в HTML-переходах не осталось. Московская олимпиада после единичного тайм-аута перепроверена и доступна, её адрес не скрывается.
