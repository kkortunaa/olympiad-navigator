# Проверка ссылок каталога — 19 октября 2026 года

Первый проход: 1 059 доступных страниц, 2 ответа 404, 1 ошибка перенаправления, 11 ошибок соединения. Две ошибки соединения оказались неподдержанными кириллическими URL в самом проверяющем коде: после исправления обе ссылки открылись. Все оставшиеся проблемные ссылки проверены повторно с увеличенным ожиданием.

## Повторная проверка

```bash
python manage.py audit_catalog_links --report link-audit.json --workers 6 --timeout 12
```

Команда читает каталог и записывает только отчёт. Повторяющиеся URL проверяются один раз. Запросы выполняются с ограниченным числом потоков; ответы 403, 429, 5xx и ошибки TLS не считаются удалёнными страницами.

## Обновление PythonAnywhere

Из папки репозитория выполнить `git pull`, активировать окружение и из папки с `manage.py` выполнить `python manage.py migrate`. Затем нажать Reload на вкладке Web. Новые миграции исправляют ссылки без повторной загрузки каталога.
