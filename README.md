# ОлимпТрек

Django-сайт с каталогом перечневых олимпиад, личными задачами и календарём активности.

Подробное объяснение устройства, аккаунтов, ограничений и доступа с другого ПК: [PROJECT_GUIDE.md](PROJECT_GUIDE.md).
Каталог, профили и расписания находятся в SQLite: `scuns/db.sqlite3`.
Гостевые задачи и избранное сохраняются в браузере, после входа — в базе данных аккаунта.
Есть избранные олимпиады, предупреждения о совпадениях туров, архивы заданий и уведомления. Выбор статуса участия удалён.

## Быстрый запуск для сокомандника

Нужны Git и Python **3.10 или новее** (рекомендуется 3.12). Проверенная ветка Django — 5.2 LTS.
Из терминала:

```bash
git clone https://github.com/kkortunaa/olympiad-navigator.git
cd olympiad-navigator
python3 start.py
```

На Windows последняя команда: `py -3 start.py` (либо `python start.py`).
Скрипт создаёт `.venv-app`, устанавливает `requirements.txt`, применяет миграции,
заполняет пустой каталог и запускает сайт: **http://127.0.0.1:8000/**.
Первому запуску нужен интернет для установки пакетов. Chrome для просмотра сайта не нужен.
Для остановки — `Ctrl+C`. Последующие запуски: `python3 start.py`.
Если порт занят: `python3 start.py --port 8002`.
Подготовка без запуска сервера: `python3 start.py --setup-only`.
После `git pull` снова запускайте `start.py`: он применяет новые миграции и при изменении
requirements устанавливает зависимости. Принудительная переустановка: `--install`.
Старое окружение `.venv` скрипт не использует.

### Что уже будет в новой базе

В репозитории есть **только открытый каталог**: 60 олимпиад, 272 профиля и 397 событий
сезона 2026/2027, сохранённые из локальной базы 15.10.2026. Даты имеют исходные отметки
проверки парсером; это снимок данных, он не обновляется сам по себе.
`bootstrap_catalog` заполняет только пустой каталог и сохраняет существующие данные.
Личные аккаунты, пароли, классы, задачи и переписки в Git не передаются.

1. Откройте `/teacher/signup/`, создайте преподавателя и класс. Скопируйте код класса.
2. В другом браузере или приватном окне создайте ученика через `/signup/`.
3. Ученик входит в «Мой класс» по коду. Теперь доступны общий чат, задания и прогресс.
4. Ученик добавляет олимпиаду в избранное или связывает с ней задачу — туры появляются
   в календаре преподавателя как **«В планах»**. «Я зарегистрировался» — отдельная отметка
   после регистрации на сайте организатора. Не отмечайте её для проверки календаря.
5. В календаре выберите подходящий месяц. Режим «Весь каталог» показывает опубликованные
   туры даже до добавления учеников.

Две отдельно запущенные копии используют разные SQLite-базы. Для общего класса и чата
оба человека должны подключаться к одному серверу сайта.

### Ручная установка

```bash
python3 -m venv .venv-app
source .venv-app/bin/activate
python -m pip install -r requirements.txt
cd scuns
python manage.py migrate
python manage.py bootstrap_catalog
python manage.py runserver
```

Windows: вместо `source` — `.venv-app\Scripts\activate`.
Для парсера нужен установленный Google Chrome; Selenium Manager подбирает драйвер.

## Заполнить или обновить базу

В активном окружении, из папки с `manage.py`:

```bash
python manage.py sync_olympiads --season 2026/2027
```

Повторный запуск обновляет записи по сезону и номеру в перечне, а события — по
олимпиаде, профилю и ссылке источника. Дубли не создаются. Другие сезоны сохраняются.

Чтобы повторять обновление каждые 6 часов:

```bash
python manage.py sync_olympiads --watch --interval 21600
```

Эта команда должна оставаться запущенной; компьютер должен иметь доступ к сети.
`Ctrl+C` останавливает процесс. При ошибке загрузки прежние расписания сохраняются,
ошибка записывается в журнал, а режим `--watch` попробует обновить данные в следующий раз.

На macOS путь к браузеру при необходимости можно указать явно:

```bash
python manage.py sync_olympiads --chrome-binary "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
```

Дополнительные параметры:

- `--limit 3` — прочитать расписания только первых трёх олимпиад; полный перечень всё равно попадёт в базу.
- `--timeout 25` — максимальное ожидание страницы в секундах.
- `--delay 0.3` — пауза между запросами, чтобы ограничить нагрузку на источники.
- `--driver-path /path/to/chromedriver` — использовать уже установленный драйвер.
- `--show-browser` — показывать браузер во время сбора.
- `--use-cache` — использовать сохранённые HTML-страницы для отладки; **не применять для актуализации дат**.
- `--index-url URL` — страница подборки Олимпиада.ру с ссылками на карточки для нужного сезона.

## Источники и ограничения

Состав и уровни берутся из [официального перечня РСОШ](https://rsr-olymp.ru/).
В сезоне 2026/2027 в нём 60 олимпиад и 272 профиля.
Подборка [Олимпиада.ру](https://olimpiada.ru/article/1266) используется только для
сопоставления названий с карточками: её предварительный список не определяет состав базы.
Неоднозначные названия не сопоставляются приблизительно.

Расписание берётся из полных страниц событий Олимпиада.ру: начало и конец,
регистрация, отборочные и заключительные туры, название профиля и источник.
Это важно: даты на компактной временной шкале могут быть обрезаны границами сезона.
Архивные события не выдаются за события текущего сезона. Неполные или приблизительные
даты сохраняются как исходный текст без придуманного числа.

Прямые ссылки регистрации ищутся в событиях и на официальных сайтах организаторов.
Если найдена только форма конкретного профиля, она указывается у этого профиля.
Новости об открытии регистрации не выдаются за форму регистрации.
Если прямой ссылки нет, сайт показывает переход на официальный сайт с пояснением.
Для одинаково подходящих разных форм парсер не выбирает адрес случайным образом.

Обновление не является подтверждением того, что регистрация сейчас открыта:
окончательный статус и условия показываются на сайте организатора.
Неопубликованные сроки остаются неизвестными. Ошибки, время проверки и статистика
каждого запуска хранятся в `ScrapeRun`; даты и ссылки источников — в `OlympiadEvent`.

В новом сезоне проверь соответствующую подборку и передай её через `--index-url`.
Парсер проверяет сезон официального перечня и прекращает импорт, если он не совпадает.
При изменении разметки источников может потребоваться обновить селекторы в `parsing.py`.

## Данные для дальнейшего использования

В каталоге доступны все названия профилей и предметы из утверждённого перечня.
Предмет выбирается в списке с поиском, профиль доступен как необязательное уточнение.
Статус регистрации выбирается кнопками, сортировка — отдельным списком. Есть фильтр избранного. Поиск учитывает
название олимпиады, профили и предметы. Например, компьютерная безопасность
попадает в информатику по предмету, даже если её профиль называется иначе.

По умолчанию карточки сортируются по ближайшему сроку окончания регистрации.
Можно выбрать порядок по открытию или окончанию регистрации, название или номер в перечне. При выборе профиля
используется срок именно этого профиля; при выборе предмета — ближайший срок
среди подходящих профилей. Если событие общее, его срок относится ко всем профилям.
Завершённая регистрация и неизвестные сроки находятся после будущих сроков.
Фильтры работают вместе, кнопка сброса возвращает весь каталог.

В карточке отдельно подписаны **открытие** и **окончание регистрации**, показаны
профиль, название периода и ссылка на полную страницу источника. Даты выводятся
как `дд.мм.гггг`. Если организатор опубликовал только одну границу, вторую не
угадываем. Отдельный фильтр позволяет выбрать текущую, будущую, завершённую
регистрацию или периоды с неизвестными датами. Для статуса «Идёт регистрация»
нужны обе опубликованные границы; текущий день определяется по московскому времени.
Время суток модель пока не хранит: точный час закрытия уточняется у организатора.

Например, Всесибирская олимпиада по информатике: регистрация на отборочный этап
открывается **19.10.2026** и заканчивается **06.11.2026**, тур — **08.11.2026**.
Это разные даты, а не два формата одного срока.

- `/olympiads/` — каталог с поиском, фильтрами и кнопками регистрации.
- `/olympiads/<id>/` — все даты и профили конкретной олимпиады.
- `/api/olympiads/` — JSON текущего сезона: олимпиады, профили, сроки и ссылки.
- `olympiads/models.py` — модели базы данных.
- `olympiads/services/parsing.py` — разбор HTML и проверка дат/ссылок.
- `olympiads/services/browser.py` — загрузка страниц через Selenium.
- `olympiads/services/sync.py` — обновление базы и журнал запусков.

Резервную копию записей можно выгрузить командой:

```bash
python manage.py dumpdata olympiads --indent 2 --output olympiads-backup.json
```

SQLite-файл и временные HTML-страницы исключены из Git. После клонирования создай
базу через `migrate` и заполни командой `sync_olympiads`, либо загрузи свою копию
через `python manage.py loaddata olympiads-backup.json`.

## Личный кабинет и участие

- `/signup/`, `/login/`, `/account/` — регистрация, вход, профиль и личные данные.
- `/account/password/` — изменение пароля после ввода текущего пароля.
- `/api/workspace/` — только данные текущего пользователя; сохранение через POST с CSRF и номером версии.
- `planner.Workspace` — задачи, избранное, статусы по ID профиля, настройки и прочитанные уведомления.

Гостевой план остаётся в браузере. В кабинете его можно перенести отдельной кнопкой:
задачи объединяются по ID, существующие статусы аккаунта сохраняются. Есть скачивание
JSON-копии и восстановление из неё. При восстановлении записи копии заменяют
совпадающие задачи и статусы, остальные записи сохраняются.

Вошедший пользователь получает план из базы, изменения автоматически сохраняются.
Открытая вкладка проверяет изменения на сервере раз в 45 секунд. Проверка версии
не позволяет молча перезаписать изменения другого устройства: при конфликте
появляются скачивание изменений и загрузка актуального плана. Несохранённый черновик
сохраняется в sessionStorage этой вкладки и восстанавливается при переходе на другую
страницу. Ошибки сохранения отображаются явно.

«Мои олимпиады» собирает избранное и олимпиады из задач подготовки. Выбор статуса
участия убран со всех страниц. Напоминания и возможные совпадения туров относятся
к этому списку; для многопрофильных олимпиад учитываются все профили.

Совпадения будущих туров определяются по пересечению полностью известных диапазонов
дат олимпиад из избранного и задач подготовки. Общие события не дублируются. Дата без опубликованной второй
границы не превращается в однодневное событие. Пересечение многодневных периодов
не доказывает совпадение точного времени: предупреждение предлагает его уточнить.

Уведомления на сайте напоминают о сроках регистрации, начале туров и невыполненных
задачах на сегодня/просроченных задачах. Можно выбрать 1, 3, 7 или 14 дней до события,
выключить напоминания, отметить их прочитанными и вернуть обратно. Напоминания о регистрации и турах относятся к «Моим олимпиадам». Прочитанные уведомления синхронизируются с аккаунтом.

Уведомления браузера включаются только кнопкой, после разрешения пользователя.
Выбор устройства и уже показанные системные уведомления хранятся локально.
Новые события проверяются раз в минуту, максимум три системных уведомления в минуту.
Доставка работает, пока сайт открыт; фонового сервиса при закрытом сайте нет.
Email, Telegram, Web Push и восстановление забытого пароля по почте не подключены.

Для рабочего сервера задайте `DJANGO_DEBUG=0`, `DJANGO_SECRET_KEY` и
`DJANGO_ALLOWED_HOSTS` (имена через запятую); нужны HTTPS и настройка веб-сервера.
В режиме разработки секрет создаётся один раз в исключённом из Git файле
`scuns/.dev-secret`. Пароли хешируются стандартным механизмом Django, формы и API
защищены CSRF, выход выполняется POST, персональные ответы запрещены для кеширования.
Локальное ограничение неудачных входов — 10 попыток за 5 минут для пары IP/логин;
при запуске нескольких процессов настройте общий кеш или ограничение на прокси.

## Задания прошлых лет

Раздел `/study/` содержит поиск архивов по названию, предмету и профилю, фильтр
«Только мои профили и избранное» и добавление разбора в план на сегодня.
Ссылки также доступны рядом со статусом профиля. Год, класс, профиль и доступные
решения выбираются уже в архиве источника. PDF-файлы не копируются на сайт.

12.10.2026 сохранены опубликованные ссылки для **268 из 272 профилей**:
239 разных страниц архивов (некоторые архивы общие для нескольких профилей).
Для четырёх профилей ссылка не найдена: биология ведомственной олимпиады,
информатика и программирование «Физтеха», искусственный интеллект Всероссийской
олимпиады по ИИ, экономика олимпиады Вернадского. Это не означает отсутствия заданий
у организаторов. Наличие ссылки не гарантирует полноту лет и решений в архиве.

`sync_olympiads` теперь обновляет и ссылки на архивы. Отдельное обновление без
повторного сбора дат:

```bash
python manage.py sync_task_links
```

Параметры: `--driver-path`, `--chrome-binary`, `--only-missing`, `--timeout 12`.
`--cached-only` извлекает ссылки исключительно из ранее сохранённых страниц Selenium.
Ошибки сохраняют прежние ссылки. В API каталога у профиля есть `id`, `tasks_url`
и `tasks_checked_at`.

## Проверки проекта

```bash
python manage.py check
python manage.py test olympiads planner
```

Проверки охватывают диапазоны дат, переход через Новый год, неизвестные даты,
сопоставление профилей, ссылки регистрации, повторный импорт и сохранение данных
при временной недоступности источника. Подробности последней проверки и предложения
по удобству находятся в [usability-audit.md](usability-audit.md).

Изменения личного кабинета 12.10.2026: применены миграции, выполнены проверка
конфигурации Django, проверка отсутствия неприменённых изменений моделей и проверка
синтаксиса JavaScript/Python; просмотрены страницы входа, каталога, подготовки и
статусов. Новые автоматические тесты на этом этапе не добавлялись и не запускались.

## Интерфейс и аккаунты — 13.10.2026

Главная содержит задачи и годовой календарь активности. Выполнения хранятся по фактической
дате отметки, отдельно от запланированной даты задачи; удаление завершённой задачи
не удаляет историю. Старым задачам без даты выполнения история не приписывается.
Кнопка «Все даты» показывает задачи за остальные дни.

Каталог, избранное и «Мои олимпиады» находятся во вкладке «Олимпиады». «Мой план» удалён из
навигации; старый адрес перенаправляет на главную. Уведомления получили отдельный адрес
`/notifications/`; кабинет содержит настройки и перенос/экспорт данных.

Лимиты: 1000 задач, 180 символов в названии, 5000 записей истории,
2 000 000 байт на сохранение/импорт. Проверены 82 Django-теста, включая вход, смену пароля,
доступ из двух сессий, изоляцию пользователей, CSRF и конфликт версий.
Браузерная проверка описана в [PROJECT_GUIDE.md](PROJECT_GUIDE.md#12-что-проверено).

## Места проведения туров — 13.10.2026

В расписании добавлена колонка «Место проведения»: дистанционный/заочный/очный
формат, опубликованное описание площадки и источник. Каждая запись тура хранит
`participation_format`, `venue`, `venue_url`, `venue_source_url`, `venue_note`,
`venue_basis` и `venue_checked_at`. Эти поля доступны и в `/api/olympiads/`.

Обычный `sync_olympiads` обновляет их вместе с расписанием. Отдельное обновление:

```bash
python manage.py migrate
python manage.py sync_venues --driver-path /path/to/chromedriver
```

Параметры: `--season 2026/2027`, `--timeout 12`, `--event-ids 104 105 106`,
`--report venue-sync-report.json`. `--cached-only` разбирает уже сохранённые страницы
без сети и сохраняет время их загрузки, а не выдаёт их за свежую проверку.

Место берётся из страницы конкретного тура; при отсутствии — из относящегося к этому
этапу описания профиля с пометкой «По описанию профиля». Адрес организатора, общий
город в шапке Олимпиада.ру, описания других олимпиад и адрес финала не выдаются за
площадку отбора. Противоречивые описания не объединяются в вымышленный адрес.
Если точных сведений нет, показывается «Площадка пока не указана» и ссылка для уточнения.

Обработан 301 тур; после проверки привязки к этапам сведения о формате или месте
сохранены для 150, из них описание места есть у 7. Остальные записи остаются без
подтверждения. Это не означает наличия точного адреса у всех 150 туров.
Отчёты: `venue-sync-2026-10-13.json`, `venue-review-refresh-2026-10-13.json`.

## Учитель и ученик

В проекте есть отдельные роли аккаунтов. Старые аккаунты после миграции остаются
учениками. Для учителя используйте `/teacher/signup/` и `/teacher/login/`, для
ученика — `/signup/` и `/login/`. Роль задаётся сервером при регистрации; смена
роли через форму профиля или JSON плана недоступна.

После обновления выполните миграции и перезапустите Django:

```sh
cd /Users/kkortunaa/Documents/project_pepepep/scuns/scuns
../.venv/bin/python manage.py migrate
../.venv/bin/python manage.py runserver
```

Учитель создаёт класс, приглашает ученика по его логину или передаёт код класса.
Ученик принимает приглашение/вводит код во вкладке «Мой класс». До присоединения
учитель не получает доступ к профилю ученика. Код можно заменить; это не удаляет
существующих учеников. Выход/исключение закрывают доступ к профилю и переписке,
сохраняя историю класса. Можно состоять в нескольких классах.

В профиле ученика учитель видит общую активность, отмеченные регистрации,
выданные задания и ответы. Одноклассникам доступны имя и счётчики прогресса;
личные задачи, ответы, регистрации и переписка других учеников не раскрываются.
Счётчик отражает самостоятельные отметки выполнения, а не автоматическую
проверку правильности решения.

На странице олимпиады ученик выбирает профиль в блоке «Я зарегистрировался»
после регистрации у организатора. Эти отметки сохраняются отдельно от избранного
и попадают в календарь преподавателей его классов. Сайт не проверяет регистрацию
в личных кабинетах организаторов. При напоминаниях отдельные отметки учитываются
по выбранным профилям; для избранного и задач сохраняется наблюдение за всеми
профилями олимпиады.

Учитель отправляет задания всему текущему классу или одному ученику. Ученик
открывает задание, оставляет ответ/ссылку и отмечает выполнение. Выполнение
попадает в календарь активности и общий прогресс, повторное сохранение ответа
не удваивает счётчик и не меняет дату выполнения. Снятие отметки отменяет
выполнение. Задания учителя отображаются также на главной ученика.

Чат приватен для пары «преподаватель—ученик» в конкретном классе. Новые сообщения
подгружаются каждые 5 секунд, пока вкладка видима. Общий чат класса доступен преподавателю и всем текущим ученикам; сообщения
сохраняются один раз и видны всем участникам. Отдельная личная рассылка остаётся
в раскрывающемся блоке преподавателя. Приглашения, задания, ответы и
сообщения сохраняют уведомления в БД; счётчик обновляется каждые 20 секунд.
Доставки при закрытом сайте, email и внешнего push-сервиса пока нет.

Календарь учителя показывает туры олимпиад из избранного, задач подготовки и
отмеченных регистраций учеников, для одного класса или всех его классов.
Доступны режимы только регистраций и всего каталога. Планы отдельно подписаны
и не считаются подтверждённой регистрацией. На дату можно навести курсор или нажать. Красный цвет означает
пересечение периодов разных туров у одного ученика, включая разные профили одной
олимпиады. Один общий тур нескольких учеников объединяется. Если известна только
одна граница периода, отмечается только эта дата с пояснением. Допуск к финалу
и точное время тура уточняются отдельно. Данные календаря обновляются при загрузке
страницы из сохранённого парсером расписания.

«Варианты» содержит банк авторских заданий, конструктор, выдачу классу или выбранным
ученикам, автопроверку, историю попыток и статистику ошибок. Старые черновики сохранены.
Условия, ответы и разборы решаются и открываются внутри сайта. ИИ-помощник Groq
подключается необязательным серверным ключом. Полные сценарии, ограничения и обновление
PythonAnywhere: [docs/practice.md](docs/practice.md).

Кнопка солнца/луны в шапке переключает тёмную и светлую темы. Выбор сохраняется
в браузере и применяется до показа страницы. Новых Python-зависимостей для этих
функций нет. Перед миграциями сохранена локальная копия БД в игнорируемой
папке `.backups/`.

Проверка: `../.venv-app/bin/python manage.py test`
из папки с `manage.py`. Проверки используют отдельную тестовую БД.
